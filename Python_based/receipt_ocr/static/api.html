Receipt extraction API

Upload a document and receive exact decimal amounts, source rows, review warnings, and per-page results. Download the OpenAPI schema.

POST /api/receipts

Send a multipart form with a required file, optional three-letter currency hint, and preview boolean (default true). The hint resolves missing or ambiguous currency symbols; an explicit printed currency takes priority.

curl -X POST http://127.0.0.1:8765/api/receipts \
  -F 'file=@/absolute/path/receipt.jpg' \
  -F 'preview=false'

If the server has RECEIPT_API_TOKEN configured, include Authorization: Bearer YOUR_TOKEN. Keep the service on localhost, or use authenticated HTTPS when connecting it to another application.

Response

{
  "filename": "receipt.jpg",
  "sha256": "...",
  "engine": "RapidOCR ...",
  "processing_ms": 4800,
  "pages": [{
    "page": 1,
    "status": "ok",
    "total": {"amount": "54.50", "currency": "CHF"},
    "tax": {"amount": "3.85", "currency": "CHF"},
    "needs_review": false,
    "confidence": 0.97,
    "warnings": [],
    "checks": {"preprocessing_consensus": "matched"},
    "candidates": [], "lines": [], "raw_text": "..."
  }]
}

The example is abbreviated. Actual responses include all readable candidates and text. Amounts are decimal strings. confidence is a heuristic evidence score, not a calibrated probability. The two preprocessing passes use the same OCR model. total: null means the system abstained. Each PDF/TIFF page is independent; there is no automatic cross-page grand total.

Limits and errors

  • JPEG, PNG, WebP, TIFF, AVIF, PDF; 20 MiB per file, 25 megapixels per page, up to 5 pages.
  • 401: missing or invalid token. 403: cross-origin upload blocked. 413: file or body too large.
  • 422: invalid document, missing file, or invalid currency hint. 500: OCR failed.
  • 503: one document is already processing. Retry after the number of seconds in Retry-After.

GET /api/health

Returns service availability, engine description, busy status, and whether token authentication is enabled. Models load lazily on the first extraction.
