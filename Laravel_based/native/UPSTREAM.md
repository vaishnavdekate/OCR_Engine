# Native OCR dependency

The `rapidocrlite` source subtree is vendored from:

- Repository: https://github.com/RapidAI/RapidOCRLite
- Commit: `9c8769008c07e13867c173c786fdc66c7fb314b4`
- License: Apache-2.0; see `rapidocrlite/LICENSE` and retained source notices.

The original C++ sources, headers and CMake files are unmodified. Python bindings, development tools, GPU shader dependencies, and model weights from that repository are not included. The application explicitly selects the PP-OCR model family, CPU backend, and the original PP-OCRv6 small weights. It does not use the experimental Indra model weights.

`receipt_ocr.cpp` is this application's narrow JSON command-line adapter. All web/API/CLI orchestration, row grouping, currency inference, monetary parsing, total selection, arithmetic, review warnings and cross-pass consensus run in Laravel/PHP. The executable does text detection and recognition only. It cannot issue application commands or interpret receipt content as instructions.

CPU inference uses the native C++ PP-OCRv6 interpreter; ONNX Runtime and Python are not linked or invoked. Input is an RGB 8-bit PPM generated by ImageMagick. A native process emits text, confidence, and four-point polygons as JSON, with no shell interpolation.

The default CPU build still compiles unused upstream model-family/backend stubs. The PP-OCR CPU selection in the adapter is fixed. Rebuild on each target architecture with `sh scripts/build-native.sh`; the included local executable is macOS arm64.
